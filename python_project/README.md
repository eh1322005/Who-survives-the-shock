# Global Resilience Index — Composite Score Predictor

A production-style data science project that analyzes resilience across 100
countries using 23 years of World Bank data (2000–2023), and trains a
machine learning model to predict a country's **Composite Resilience Score**
from its six domain scores.

## Project Structure

```
.
├── Global_Resilience_Final.ipynb   # Full EDA + ML + MLOps notebook
├── app.py                          # Streamlit prediction app
├── predict.py                      # CLI prediction script
├── model_loader.py                 # Loads trained pipeline + metadata
├── utils.py                        # Logging, validation, shared helpers
├── config.py                       # Paths, constants, env var overrides
├── requirements.txt
├── Deployment_Guide.md
├── .gitignore
└── artifacts/                      # Generated by the notebook (Section 11)
    ├── resilience_model_latest.joblib
    ├── resilience_model_latest.pkl
    └── model_metadata.json
```

## What's in the Notebook

1. **Sections 1–9 (original analysis):** data loading, cleaning, feature
   engineering, 17 KPIs, 36 analytical tables (A1–A36), visualizations, and
   business insights — unchanged from the original project.
2. **Section 10 — Machine Learning:** defines the regression problem
   (predict Composite Resilience Score from domain scores + region), builds
   a `ColumnTransformer` + `Pipeline`, trains 10+ models (Linear/Ridge/
   Lasso/ElasticNet, Decision Tree, Random Forest, Extra Trees, Gradient
   Boosting, SVR, KNN, plus XGBoost/LightGBM/CatBoost if installed),
   compares them, tunes the top candidates with `GridSearchCV` and
   `RandomizedSearchCV`, and analyzes feature importance, SHAP (optional),
   and residuals.
3. **Section 11 — MLOps:** saves the winning pipeline with `joblib` and
   `pickle`, writes `model_metadata.json`, sets up logging, and verifies
   reproducibility by reloading the saved model and comparing predictions.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the notebook end-to-end to train and save the model
jupyter nbconvert --to notebook --execute Global_Resilience_Final.ipynb

# 3. Launch the prediction app
streamlit run app.py
```

Or use the CLI directly once a model is trained:

```bash
python predict.py --digital 0.6 --economic 0.5 --food 0.7 \
    --healthcare 0.65 --political 0.55 --climate 0.6 \
    --region "Europe & Central Asia"
```

## Model

- **Target:** Composite Resilience Score (continuous, 0–1).
- **Features:** 6 domain scores (Digital Infrastructure, Economic Fragility,
  Food Security, Healthcare, Political Stability, Climate & Energy) +
  one-hot encoded Region.
- **Selection criterion:** highest Test R² across all trained and tuned
  models (see Section 10.5 of the notebook for the full leaderboard).

## Notes

- XGBoost, LightGBM, CatBoost, and SHAP are optional. If not installed, the
  notebook logs a message and continues with the remaining models — nothing
  breaks.
- See `Deployment_Guide.md` for environment setup and troubleshooting.
